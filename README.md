# Plataforma de Agentes

Agentes de IA que atendem e qualificam leads no **Instagram** (várias contas) e, em seguida, no **WhatsApp**. Inclui automações por palavra-chave no estilo ManyChat, dashboard e envio dos leads qualificados para ferramentas externas.

- Arquitetura, regras do Instagram, modelo de dados e roadmap: [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md)
